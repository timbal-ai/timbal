────────────────────────────────────────────────────────────────────────────
  AgentExecutor vs create_react_agent vs Timbal  (Scenario 2: 3-tool chain)
────────────────────────────────────────────────────────────────────────────

  AgentExecutor was removed in LangChain 1.x.
  LangChain fully deprecated the LCEL agent pattern (AgentExecutor +
  create_tool_calling_agent) and committed to LangGraph as the sole
  agent runtime. create_react_agent (langgraph.prebuilt) IS the
  current official agent API — the benchmark already covers it.

  To test AgentExecutor: install langchain==0.3.x (conflicts with
  langchain-core>=1.x which langgraph requires).

────────────────────────────────────────────────────────────────────────────
  All measurements reuse 1 pre-built agent/graph (creation excluded).
  LLMs faked via message inspection. Timbal traces cleared between batches.
  Both frameworks run natively async on a single shared instance.
