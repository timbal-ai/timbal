────────────────────────────────────────────────────────────────────────────────────────
  Scenario A: measures pure per-branch scheduling cost (task creation, span
  lifecycle, param resolution). Both frameworks pay this on every parallel step.

  Scenario B: verifies true concurrency. asyncio.sleep() yields to the event
  loop so all N branches run concurrently. Latency should be ~1 ms flat.
  If latency scales with N, the framework is serialising parallel branches.

  Timbal uses one asyncio.Task per step. Overhead scales linearly with N.
  LangGraph uses a Pregel superstep model. Different per-branch cost structure.
