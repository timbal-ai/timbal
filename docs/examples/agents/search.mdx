title: "Web Search"
description: "Use provider-native web search or an executable search service with any tool-capable model"
---

Agents can search the web using the built-in `WebSearch` tool. Native `WebSearch()` works with Anthropic and OpenAI/xAI Responses. Select an executable search provider to use it with other tool-capable models.

<Note>
See the [Model Reference](/models/overview) to check which specific models support web search.
</Note>

```python
from timbal import Agent
from timbal.tools import WebSearch

# Works with OpenAI or Anthropic models
agent = Agent(
    name="SearchAgent",
    model="openai/gpt-5.1",
    tools=[WebSearch()],
    system_prompt="Search the web for current information."
)

# Agent will automatically use search when needed
result = await agent(
    prompt="When was the last match of Liverpool?"
).collect()
```

## Search with another model provider

Set `TAVILY_API_KEY` and use an executable search tool:

```python
agent = Agent(
    name="search_assistant",
    model="google/gemini-2.5-flash",
    tools=[WebSearch(provider="tavily")],
    system_prompt="Search for current information and cite the sources you use.",
)
```

Other executable selectors are `scraperapi`, `cala`, `firecrawl`, and `google`. See [Tools](/agents/tools#websearch) for credential resolution and native search constraints.

## Key Features

- **Real-time Information**: Access current web data and news
- **Automatic Tool Selection**: Agent decides when to search
- **Citation Support**: Includes source links in responses
