## Usage

```python
from timbal import Agent

agent = Agent(
    name="kimi",
    model="moonshot/kimi-k3",
    model_params={"reasoning_effort": "max"},
    tools=[],
)

result = await agent.collect(prompt="Explain Kimi K3 in one sentence.")
print(result.output.collect_text())
```

## Cache billing and lifecycle

K3 cache reads cost &#36;0.30 per million tokens. Cache writes cost &#36;3 for the default 5-minute TTL or &#36;6 for 1 hour. Reads, writes, and uncached input are disjoint; do not add a write charge on top of ordinary input for the same tokens. The catalog stores the 5-minute write rate. The current Chat Completions collector does not distinguish write TTLs, so 1-hour writes require separate reconciliation against provider billing. See [cache pricing and usage fields](https://platform.kimi.ai/docs/guide/context-caching).

K3 requires a successful account top-up of at least &#36;1. [K3 specifications](https://platform.kimi.ai/docs/guide/kimi-k3-quickstart) and the [model list](https://platform.kimi.ai/docs/models) were checked October 3, 2026. K2.5 and Moonshot V1 were discontinued August 31; the K2 series was discontinued May 25. These are already absent from this provider's catalog.

All listed token and cache prices were verified October 3, 2026 from the [pricing page's embedded model tables](https://platform.kimi.ai/docs/pricing/chat), crosschecked against the [platform model cards](https://platform.kimi.ai/) and [cache guide](https://platform.kimi.ai/docs/guide/context-caching). HighSpeed pricing is published in the detailed table only. Prices exclude applicable taxes.
