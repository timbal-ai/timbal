### How cache and fast-mode pricing is tracked

Claude 4.6 and later models bill the full 1M window at standard rates, except Haiku 5.5: prompts over 100,000 tokens use a higher rate for the full request. For global streaming requests, Timbal's collector emits one unit per disjoint token bucket. Multipliers below are relative to the model's input rate unless specified otherwise:

| Anthropic `usage` field | Usage key on `OutputEvent.usage` | Rate |
| --- | --- | --- |
| `input_tokens` | `input_tokens` | 1x |
| `cache_read_input_tokens` | `cache_read_input_tokens` | 0.1x (0.05x on Opus 5.5 and Sonnet 5.5; 0.025x on Fable 5.1) |
| `cache_creation.ephemeral_5m_input_tokens` | `ephemeral_5m_input_tokens` | 1.25x |
| `cache_creation.ephemeral_1h_input_tokens` | `ephemeral_1h_input_tokens` | 2x |
| `cache_creation_input_tokens` (only when no valid per-TTL breakdown is reported) | `cache_creation_input_tokens` | 1.25x fallback; assumes 5m TTL |
| `output_tokens` | `output_tokens` | output rate |
| `server_tool_use.*_requests` | e.g. `web_search_requests` | per call |

`output_tokens_details.thinking_tokens` is a subset of `output_tokens` and is **not** emitted as a separate unit (it would be billed twice). On Opus 5.5 / Opus 5 / Opus 4.8, `usage.speed == "fast"` ([fast mode](https://platform.claude.com/docs/en/build-with-claude/fast-mode), 2x) suffixes every token unit with `_fast`, e.g. `anthropic/claude-opus-5-5:output_tokens_fast`; pass `model_params={"extra_body": {"speed": "fast"}, "extra_headers": {"anthropic-beta": "fast-mode-2026-02-01"}}` to opt in. If a stream is interrupted before the final `message_delta`, the prompt-side units are still recorded from `message_start` (Anthropic charges them regardless); output is left unbilled.

On Haiku 5.5, the tier threshold uses `input_tokens + cache_read_input_tokens + cache_creation_input_tokens`. Exactly 100,000 prompt tokens still use the lower rates. Above that boundary, every token unit receives `_long_context`, including output and both cache-write durations, e.g. `anthropic/claude-haiku-5-5:ephemeral_1h_input_tokens_long_context`. The per-TTL write breakdown is already included in `cache_creation_input_tokens` and is not counted twice. Per-call tool fees keep their original units. The same tier selection applies to prompt usage from interrupted streams.

Web search costs &#36;0.01 per search plus token charges; web fetch has no additional per-call fee. Code execution is free alongside the current web search/fetch tools; otherwise Anthropic bills execution time, with 1,550 free hours per organization per month, then &#36;0.05 per container-hour and a five-minute minimum. A `code_execution_requests` count alone is insufficient to calculate that charge.

The catalog stores global standard input, output, cache-read, and both cache-write rates explicitly: `cached_input_price` for reads, `cache_write_price` for 5m writes, and `cache_write_1h_price` for 1h writes. The SQL generator omits each missing or null rate independently, including its fast-mode variant; it never derives cache prices from the input price. Omitted rates are unknown, not free. The collector does not distinguish Batch API or US-only inference pricing in its usage keys. Apply those provider modifiers separately when reconciling billing. An aggregate cache-write count without a valid TTL breakdown cannot exactly price 1h or mixed-TTL writes.

## Using Haiku 5.5

Set `ANTHROPIC_API_KEY` and select the full model ID:

```python
from timbal import Agent

agent = Agent(
    name="classifier",
    model="anthropic/claude-haiku-5-5",
    max_tokens=4096,
    model_params={"output_config": {"effort": "medium"}},
)
```

Adaptive thinking is on by default, and thinking tokens count toward `max_tokens`. Timbal collects text and thinking blocks separately. Omit non-default sampling parameters. Haiku 5.5 uses the newer tokenizer, which produces approximately 30% more tokens for the same text than Haiku 4.5; recount prompts and budgets before migrating. Replay stored thinking blocks through the account that produced them or a linked account.

Automatic prompt caching is enabled by Timbal. The 100K pricing threshold includes uncached input, cache reads, and cache writes; output uses the rate selected by the prompt length. `scripts/generate_costs_sql.py` emits both standard and `_long_context` token rates, including 5m and 1h cache writes. Apply the generated SQL when updating a billing database; changing the catalog alone does not update stored rates.

Haiku 5.5 specs and pricing verified October 7, 2026 against the [model specifications](https://platform.claude.com/docs/en/models/haiku-5-5/overview), [migration guide](https://platform.claude.com/docs/en/models/haiku-5-5/migration-guide), and [API pricing](https://platform.claude.com/docs/en/about-claude/pricing).

## Using Sonnet 5.5

Set `ANTHROPIC_API_KEY` and select the full model ID:

```python
from timbal import Agent

agent = Agent(
    name="coder",
    model="anthropic/claude-sonnet-5-5",
    max_tokens=16000,
    model_params={"output_config": {"effort": "high"}},
)
```

Omit `thinking` to use adaptive thinking. To turn off up-front thinking, pass `model_params={"thinking": {"type": "between_tools"}, "output_config": {"effort": "high"}}`; this requires `high` effort or below. Use `auto` with strict tools or structured outputs instead of forced tool selection. Leave `temperature`, `top_p`, and `top_k` at their defaults.

With adaptive thinking, progress text between tool calls arrives in thinking blocks and is omitted by default. Set `thinking.display="summarized"` to receive it; `between_tools` returns it without a display setting. Preserve thinking blocks and the preceding conversation unchanged when replaying them. Native computer use on the Claude API requires `computer_toolset_20260801`; the older `computer_20251124` tool is rejected.

Automatic prompt caching is enabled by Timbal; Sonnet 5.5 requires at least 512 cacheable tokens. All prices above are USD per 1M tokens except per-call/time-based tool fees. The 50% Batch API discount and 10% US-only inference premium stack across token categories. Partner cloud pricing and negotiated discounts may differ.

See the [Sonnet 5.5 specifications](https://platform.claude.com/docs/en/models/sonnet-5-5/overview) and [migration notes](https://platform.claude.com/docs/en/models/sonnet-5-5/whats-new-sonnet-5-5). Sonnet 5.5 cache reads were halved on October 7, 2026; standard reads now cost &#36;0.10 per 1M tokens (&#36;0.05 with Batch, &#36;0.11 with US-only inference). Anthropic catalog token and cache prices verified October 7, 2026 against [Anthropic's price list](https://platform.claude.com/docs/en/about-claude/pricing).
