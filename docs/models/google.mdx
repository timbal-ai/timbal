## Gemini 4 Argon

`google/gemini-4-argon`

**Generally available since October 13, 2026**, through the paid Gemini API and AI Studio.
Google lists `gemini-4-argon` as stable; it is no longer limited to the earlier trusted-tester release.
See the [launch announcement](https://cloud.google.com/blog/products/ai-machine-learning/gemini-4-argon-available-on-google-cloud/).

- Standard input / output / cached input: **&#36;2 / &#36;10 / &#36;0.10** through November 30, 2026;
  **&#36;4 / &#36;20 / &#36;0.20** from December 1. The catalog and generated cost SQL use the latter, post-promotion rates.
- Batch and Flex: **&#36;1 / &#36;5 / &#36;0.05**, then **&#36;2 / &#36;10 / &#36;0.10** on December 1.
- Priority: **&#36;3.60 / &#36;18 / &#36;0.18**, then **&#36;7.20 / &#36;36 / &#36;0.36** on December 1.
- Invite-only Contributor tier: same token rates as Batch/Flex, with data used to improve Google's products.
- No free API tier. Output prices include thinking. Implicit caching only; no explicit cache creation or storage charge.
- Search and Maps grounding each have a shared 5,000-query monthly allowance, then **&#36;14 per 1,000 queries**.
  These native tool charges are separate from Timbal's text-token estimates.

[Full pricing](https://ai.google.dev/gemini-api/docs/pricing#gemini-4-argon)

The [model specifications](https://ai.google.dev/gemini-api/docs/models/gemini-4-argon) give a **1,048,576-token unified input/output window**,
with a default synchronous output limit of **65,536**. Text, image, audio, video, and PDF input are supported; output is text.
Tools, structured output, and reasoning are supported. Thinking levels are `low`, `medium` (default), and `high`.

Set `GEMINI_API_KEY` for direct access, or use an authorized Timbal platform configuration:

```python
from timbal import Agent

agent = Agent(
    name="argon",
    model="google/gemini-4-argon",
    max_tokens=32768,
    model_params={"reasoning_effort": "medium"},
)
```

Timbal uses Google's [OpenAI-compatible streaming chat API](https://ai.google.dev/gemini-api/docs/openai).
The model's default reasoning level also applies when `model_params` is omitted. Google ignores sampling parameters
such as `temperature` and `top_p` on Argon. Explicit caching is unsupported.
Native long decode can use the remaining unified window, but requires background execution or continuation handling;
Timbal's Agent chat route does not implement that continuation protocol. See the
[migration guide](https://ai.google.dev/gemini-api/docs/latest-model#migration-checklist).

## Gemini 3.8, 3.7, and 3.6 Flash

<Note>
All three use published post-promotion Standard input / output / cached-input rates of **&#36;1.50 / &#36;7.50 / &#36;0.15**, effective January 1, 2027.
This timing is published on the [pricing page](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.8-flash).
The catalog already uses these post-promotion rates; temporary introductory discounts are excluded.
Post-promotion cache storage is an additional &#36;1 per million token-hours.
Batch and Flex token rates are half Standard; Priority token rates are 1.8 times Standard. These are not the default catalog prices.
</Note>

## Cost accounting boundaries

The catalog's `input_price`, `output_price`, and `cached_input_price` describe text rates; `long_context` records full-request thresholds.
Audio, generated images/video, grounding calls, and cache storage are not represented by these fields and are not included in text-only cost estimates.
Even when a model prices audio input like text, that does not add an audio charge to the text cost table.
Cached audio also has its own rates on some models; do not apply the text-cache rate to it.

Standard cache storage for 3.1 Pro and 2.5 Pro is &#36;4.50 per million token-hours; the other listed general-purpose Flash models at post-promotion rates use &#36;1.
Google Search grounding on Gemini 3 is billed per individual search query after its shared monthly allowance,
while Gemini 2.5 uses grounded-prompt billing after its daily allowance. A request can trigger multiple search queries.
Consult [Google's billing details](https://ai.google.dev/gemini-api/docs/pricing) before estimating an entire workflow.
