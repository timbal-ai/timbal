<Note>
Reviewed October 3, 2026 against Google's [model catalog](https://ai.google.dev/gemini-api/docs/models),
[pricing](https://ai.google.dev/gemini-api/docs/pricing), [release notes](https://ai.google.dev/gemini-api/docs/changelog),
and [deprecations](https://ai.google.dev/gemini-api/docs/deprecations).
Prices below are USD per **1 million tokens**, paid **Standard** tier, using published post-promotion rates and excluding temporary introductory discounts.
Output rates include thinking tokens for reasoning models. Batch, Flex, Priority, free-tier allowances,
cache storage, grounding, and media generation are separate charges or pricing plans.
</Note>

## Gemini 4 availability

Google [announced Gemini 4 Argon on September 30](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/).
Access is currently limited to trusted testers and Fairwind cyber defenders; the announcement describes broader paid API access as forthcoming.
There is no public Gemini 4 model ID in the Gemini API catalog as of this review, so Timbal does not register a speculative ID.
The announced post-promotion input / output price is &#36;4 / &#36;20. These are announced future rates, not a currently callable public API price.

## Gemini 3.8, 3.7, and 3.6 Flash

<Note>
All three use published post-promotion Standard input / output / cached-input rates of **&#36;1.50 / &#36;7.50 / &#36;0.15**, effective January 1, 2027.
This timing is crosschecked in the [latest-model guide](https://ai.google.dev/gemini-api/docs/latest-model#pricing).
The catalog already uses these post-promotion rates; temporary introductory discounts are excluded.
Post-promotion cache storage is an additional &#36;1 per million token-hours.
Batch and Flex token rates are half Standard; Priority token rates are 1.8 times Standard. These are not the default catalog prices.
</Note>

## Image and speech models

audio synthesis is not provided by the Google Agent chat route. Media rates must not be used as text-output rates.

## Cost accounting boundaries

The catalog's `input_price`, `output_price`, and `cached_input_price` describe text rates; `long_context` records full-request thresholds.
Audio, generated images/video, grounding calls, and cache storage are not represented by these fields and are not included in text-only cost estimates.
Even when a model prices audio input like text, that does not add an audio charge to the text cost table.
Cached audio also has its own rates on some models; do not apply the text-cache rate to it.

Standard cache storage for 3.1 Pro and 2.5 Pro is &#36;4.50 per million token-hours; the other listed general-purpose Flash models at post-promotion rates use &#36;1.
Google Search grounding on Gemini 3 is billed per individual search query after its shared monthly allowance,
while Gemini 2.5 uses grounded-prompt billing after its daily allowance. A request can trigger multiple search queries.
Consult [Google's billing details](https://ai.google.dev/gemini-api/docs/pricing) before estimating an entire workflow.
